# Reproducibility manifest

Written 30 October 2026 for the manuscript revision (review items R2, R9, R10).
The authoritative manuscript is `paper/EV-PIL-manuscript.docx` and its Word
render `paper/EV-PIL-manuscript.pdf`, built from `paper/sections/` by
`python3 paper/build_paper.py` at the commit tagged `manuscript-2026-10-30`.
Earlier files named `EV-PIL-mock-paper-IEEE-Access.*` are superseded.

Labels follow the manuscript: target-measured (timing, counters, memory on the
ESP32-S3), PIL-evaluated (vehicle outcomes the host model computed while the
controller ran on the target), host-simulated (host only).

## Environment

Python 3.11 or newer, `python3 -m pip install -e '.[dev]'`. Drive cycles and
logged trips are not in Git; `python3 scripts/build_cycles.py` fetches the
cycles, and `docs/dataset-provenance.md` lists the trip files. Scripts that
import the package run as `PYTHONPATH="src:." python3 scripts/<name>.py`.
